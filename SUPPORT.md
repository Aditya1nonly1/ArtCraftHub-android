# Getting help

- **How do I…?** Check the [README](README.md) first, then ask in
  [Discussions](https://github.com/l41n-pr0t0/ArtCraftHub-android/discussions).
- **Something's broken in the hub:** open a
  [bug report](https://github.com/l41n-pr0t0/ArtCraftHub-android/issues/new?template=bug_report.yml).
  Include your hub version (Settings) and phone model.
- **Something's broken in an ArtCraft app** (ProCraft, PdfCraft, …): report it in
  [that app's repository](https://github.com/artcraft-android). The hub only installs them.
- **A security problem:** report it privately, as described in [SECURITY.md](SECURITY.md).

## Common problems

**"GitHub limit reached. Try again after HH:MM."** GitHub allows 60 requests an hour without an
account. The hub caches answers, so this only happens after many refreshes in a short time. Wait
until the time shown.

**"This app was installed from another source."** The app on your phone was signed with a
different key (for example, built yourself), and Android won't update it with the release.
Uninstall it, then install it from the hub.

**Obtainium says "Could not find a suitable release" for an ArtCraft app.** Turn on **Include
prereleases** for that app in Obtainium; the ArtCraft apps only publish pre-releases so far.

This is a hobby project maintained by one person, so answers can take a few days.

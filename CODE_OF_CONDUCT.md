# Code of conduct

This project is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## Our pledge

We want taking part in this project to be a harassment-free experience for everyone, whatever
their age, body, disability, ethnicity, sex characteristics, gender identity and expression, level
of experience, education, socio-economic status, nationality, appearance, race, caste, colour,
religion, or sexual identity and orientation.

## What we expect

- Be kind and patient, especially with people asking their first question or opening their first
  pull request.
- Respect different opinions and experiences.
- Give and accept constructive feedback about the work, not the person.
- Take responsibility for mistakes and learn from them.

## What isn't acceptable

- Sexualised language or imagery, or unwelcome sexual attention.
- Trolling, insults, or personal or political attacks.
- Public or private harassment.
- Publishing someone else's private information, such as an address or email, without permission.
- Anything else that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in the repository (issues, pull requests, discussions, reviews) and when someone
represents the project elsewhere.

## Reporting

Report behaviour that breaks this code privately to the maintainer,
[@l41n-pr0t0](https://github.com/l41n-pr0t0), through
[Security → Report a vulnerability](https://github.com/l41n-pr0t0/ArtCraftHub-android/security/advisories/new)
(start the title with "Conduct:"; only the maintainer can read it). You can also use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. Reports are handled in confidence.

## Enforcement

Depending on what happened, the maintainer may:

1. **Correct:** a private note explaining what was wrong.
2. **Warn:** a warning, with consequences for continued behaviour.
3. **Temporarily ban:** no interaction with the project for a set time.
4. **Permanently ban:** for a pattern of violations, harassment, or aggression towards people.
